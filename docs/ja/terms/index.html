適用とサービス

本規約は、sunagaku（運営者）が提供するBestShotアプリとオンライン選定サービスの利用に適用します。内容を確認して利用してください。未成年者は適用法に応じて保護者の同意を得てください。

BestShotは、利用者の同意に基づいてAIで動画から写真を選ぶためのツールです。新しい版の写真選定にはインターネット接続と外部への候補画像の送信が必要です。写真の保存や共有前に、利用者自身で結果を確認してください。

写真・動画に関する権利

動画・写真等に関する利用者または権利者の権利は、そのまま各権利者に帰属します。運営者は、本サービスの提供に必要な処理の範囲でのみ、送信された候補画像・選定条件を扱います。

利用者は、撮影、読み込み、AIへの送信、保存、共有について必要な権利・同意を確保してください。他人の肖像、プライバシー、著作権、秘密情報を侵害する使い方や、同意のない親密な画像、子どもの性的搾取等の違法なコンテンツの利用を禁止します。

禁止行為と接続コード

  • 法令に違反する利用、他人への嫌がらせ、権利侵害、不正アクセス、サービスや第三者への攻撃を行わないでください。
  • 技術的な制限や利用上限を回避したり、過剰な自動リクエストでサービスの運用を妨げたりしないでください。
  • テスト用接続コードを公開・再配布せず、適切に管理してください。漏えいが疑われる場合は運営者へ連絡してください。
  • AIによる写真の評価を、本人確認や、人物の健康・機微な属性・採用等の重大な判断に利用しないでください。

AI選定と外部サービス

AIによる順位とスコアは参考情報であり、正確性、好みへの一致、特定の成果を保証しません。新しい版では選定理由の文章や端末内だけで選定する選択肢を提供しません。

オンライン選定はCloudflareおよびOpenAIを利用し、通信状況、処理先の制約、安全性判断、利用上限等により失敗・遅延する場合があります。情報の送信先・保持等はプライバシーポリシーに記載します。

ベータ版と料金

ベータ版には不具合、機能変更、配信期限、利用の終了があり得ます。旧版では招待用の接続コード、新しいアカウント利用版ではAppleのサインインが必要です。大切な写真・動画は利用者自身で別途保存してください。

アカウント利用版の無料枠は1日最大3回、BestShot Proは最大30回のAI選定です。利用枠はUTCの0時に更新します。Proは自動更新の月額購読で、価格・期間・更新条件はAppleの購入画面で確認できます。無料期間・年額プラン・家族共有は提供しません。購入は利用者がAppleの確認画面で確定した場合にのみ行われます。購読はAppleのアカウント設定で管理・解約してください。アカウントやアプリの削除では購読は解約されません。

利用許諾とAppleの条件

アプリ自体の著作権・商標等は運営者または正当な権利者に帰属します。利用者には、適用される条件に従ってアプリを利用する権利を認めます。

Apple経由で配信されるアプリの利用許諾は、別途カスタムEULAが提示されない限りAppleの標準使用許諾契約に従います。本規約はサービスの利用条件を補足します。Appleの条件または適用法が優先する事項では、それらに従います。TestFlightの利用にはAppleのテストサービス条件も適用されます。
