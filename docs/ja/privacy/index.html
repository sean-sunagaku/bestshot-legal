sunagaku.dx@gmail.com

端末内で扱う情報

  • 撮影・読み込みした動画、抽出した写真、撮影イメージ、選定結果、日時などのアプリ内履歴を端末のアプリ領域に保存します。マイクを許可した場合、撮影動画に音声が含まれます。
  • 接続コードやアカウントの認証情報は端末のKeychainへ、利用規約・AI利用と送信への同意の版・同意日時・送信先、および設定は端末内へ保存します。環境別アプリの保存領域と接続先を分離します。
  • 写真ライブラリへの保存と他のアプリへの共有は、利用者が操作した場合に行います。iOSや利用者のバックアップ設定によって、端末内データがAppleのバックアップに含まれる場合があります。

オンラインAI選定で送信する情報

送信前の確認画面で同意すると、最大12枚の縮小JPEG候補画像、選定条件（自由入力の文を含む）、フレームID、動画内の経過時刻、端末で算出した画質スコアを、BestShotサーバーを経由してOpenAIへ送信します。元動画全体、動画の音声、高解像度の抽出写真をAI選定のために送信することはありません。

画像には人物の顔、背景、文字などが含まれる場合があります。撮影・送信する権利と、必要な本人・保護者等の同意を確認してください。機微な情報を画像や自由入力の文に含めないでください。

AIで写真を選ぶには、AI利用とCloudflare・OpenAIへの送信への個別同意が必要です。利用規約への同意だけでは送信を許可しません。動画ごとの送信前確認で取り消せます。設定から同意を撤回した場合や送信先・説明の版が変わった場合は、再同意するまで送信しません。すでに処理・送信した情報をこの操作だけで回収することはできません。

サーバーの保存内容と利用目的

BestShotのデータベースには、選定ID、選定条件、処理方式・モデル名、候補枚数、選んだフレームID・順位・スコア、作成時刻と利用枠の記録を保存します。選定の提供、障害対応、不正利用と過剰利用の防止に用います。新しい版では選定理由の文章を生成・表示しません。

候補画像、元動画、接続コードは、このデータベースに保存しません。画像は通信・処理の過程で一時的に扱われます。通常の処理でリクエスト本文やOpenAIのエラー本文をアプリケーションログへ出力しません。

アカウント機能が有効な版では、Appleのユーザー識別子、BestShotのアカウントID、認証・再送防止情報、アカウントにひもづく利用枠、Appleの署名付き取引に基づく購読情報を扱います。認証の更新と退会時の認可取消に必要なAppleのトークンをサーバーで暗号化して保管します。Appleの認証情報にメールアドレスが含まれる場合があります。氏名やメールアドレスの別途入力は求めず、広告識別子による追跡や情報の販売は行いません。

処理を行うサービスと国外での取扱い

  • OpenAI：候補画像・選定条件等を処理して選定結果を返します。Responses APIにstore: falseを指定していますが、すべての保存を無効にするものではありません。不正利用監視等の保持、画像の安全性確認、その他の例外はOpenAIのAPIデータの取扱いと利用設定に従います。
  • Cloudflare：BestShot APIの通信・実行とデータベースを提供します。IPアドレス等の接続情報がインフラの運用・セキュリティのために処理される場合があります。Cloudflareのプライバシーポリシーをご確認ください。
  • GitHub Pages：本サイトを配信します。GitHubはセキュリティのため閲覧者のIPアドレスを記録します。本サイトに独自の広告・アクセス解析スクリプトやCookieによる追跡は設置していません。GitHubのプライバシーステートメントをご確認ください。
  • Apple：サインイン、アプリの配信、アプリ内購入・自動更新購読、取引の照合、利用者が送信したフィードバック、写真ライブラリ・端末バックアップ等を提供します。Appleのプライバシーポリシーが適用されます。
  • 問い合わせメールには、返信先メールアドレスと利用者が記載した内容が含まれます。対応・本人確認に必要な範囲で利用します。上記サービスやメール基盤の処理に伴い、日本以外の国・地域で情報が取り扱われる場合があります。各提供者の保護措置と適用法に従って取り扱います。

保存期間

端末内の履歴・画像・動画は、利用者が削除するまで保存します。写真アプリや共有先に作成したコピーは別途管理してください。バックアップの保持・復元には、そのサービスの設定が適用されます。

アカウントにひもづくサーバー記録には通常の自動削除期限を設けず、アカウント削除時に選定メタデータ・利用枠・購読照合記録・認証情報を削除します。Apple認可の取消や削除が未完了の場合、必要な暗号化情報を再試行のため保管します。削除完了の受領証は1日、認証再送防止の仮名化記録は10分を有効期限とし、期限後の保守処理で消去します。削除前のアプリ画面にも適用される保持内容を表示します。旧接続コード方式のアカウントにひもづかない記録は、識別可能な削除依頼に対応するまで残る場合があります。

OpenAI等の処理先・バックアップ・セキュリティ記録には、それぞれの保持方針や法令に基づく期間が適用されます。即時の完全消去を保証するものではありません。問い合わせ内容は対応と必要な記録保持のために保管し、不要となった情報の削除は依頼できます。

同意の撤回、削除とその他の権利

今後のAI送信は、送信前確認で取り消すか、設定の「AI利用・送信の同意」から同意を撤回して止められます。カメラ・マイク・写真への権限はiOSの設定から変更できます。撤回前に行われた処理には影響しません。

端末内の撮影データはライブラリから削除できます。アカウント利用版ではアプリのアカウント削除からAppleで再認証し、サーバー側の削除を依頼できます。アカウント削除はAppleの購読解約とは別です。データの削除をご確認ください。

適用法に基づく開示、訂正、削除、処理の制限、異議申立て、データの受領・移転等はメールでご相談ください。適用条件と本人・対象情報の確認のうえ対応します。居住地域の監督機関へ苦情を申し立てる権利が認められる場合があります。

未成年者、安全管理と変更

未成年者は、適用法に応じて保護者の同意を得て利用してください。BestShotは子ども向けのサービスとして提供していません。子どもの情報の取扱いに懸念がある場合はご連絡ください。

通信の暗号化、環境別のAPI・DB・認証情報の分離、Apple認証または接続コードによるアクセス制御、保存するAppleトークンの暗号化、公開共有履歴APIを設けない構成などで情報を保護します。端末の共有や、写真の書き出し・共有先での取扱いにもご注意ください。

機能や情報の取扱いが変わる場合は本ページを更新します。重要な変更はアプリまたは本サイトでお知らせし、新たな同意が必要な処理では事前に同意を求めます。
