撮影と動画の読み込み

カメラで5秒の動画を撮影するか、写真ライブラリから30秒以内の動画を選びます。希望の撮影イメージを選ぶか自由文で入力して、選定を進めてください。

カメラやマイク、写真保存の権限で困った場合は、iPhoneの「設定」からBestShotの許可を確認してください。マイクを許可しない場合でも、音声なしでの撮影を利用できます。

AI選定と接続エラー

AI選定にはインターネット接続と、利用中の版に応じたAppleサインインまたは招待用接続コードが必要です。OpenAI APIキーを入力する必要はありません。AI利用・送信の個別同意と、動画ごとの送信前確認を経て候補画像を送信します。

接続コードのエラーは招待時の案内をご確認ください。利用上限やタイムアウトの表示が出た場合は時間をおいて再試行してください。利用上限はベータ版の運用状況によって変わる場合があります。

画像を送信したくない場合は送信前に取り消すか、設定の「AI利用・送信の同意」から撤回してください。新しい版には端末内だけで選定するモードはありません。ライブラリの閲覧や端末内の保存済みデータの管理は続けられます。

保存、共有と削除

選ばれた3枚の写真と元動画はアプリ内ライブラリに保存されます。結果画面から写真アプリに保存したり、iOSの共有機能で他のアプリへ送ったりできます。

アプリ内ライブラリの撮影データのメニューから「削除」を選ぶと、その撮影の写真3枚と元動画を削除します。写真アプリに保存したコピーや共有先のデータは残ります。データの削除もご確認ください。

料金と対応言語

アカウント利用版の無料枠は1日最大3回、BestShot Proは最大30回のAI選定です。利用枠はUTCの0時に更新します。Proは自動更新の月額購読で、価格・期間・更新条件はAppleの購入画面で確認できます。無料期間・年額プラン・家族共有は提供しません。購入は利用者がAppleの確認画面で確定した場合にのみ行われます。購読はAppleのアカウント設定で管理・解約してください。アカウントやアプリの削除では購読は解約されません。

本サイトは日本語、英語、中国語（簡体字・繁体字）、韓国語でご覧いただけます。新しいアプリは日本語・英語・中国語（簡体字）・韓国語に対応します。サイトの言語切替はアプリの表示言語を変更しません。
