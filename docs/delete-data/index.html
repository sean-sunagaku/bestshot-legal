端末内の写真・動画

  • BestShotのライブラリを開き、対象の撮影データのメニューで「削除」を選びます。確認すると、その撮影の写真3枚と元動画がアプリ内から削除されます。
  • 写真アプリに書き出したコピーは、写真アプリで別途削除してください。「最近削除した項目」やiCloud写真、端末バックアップの設定もご確認ください。共有したデータは共有先でも削除が必要です。
  • 今後のAI送信は、送信前確認で取り消すか、設定の「AI利用・送信の同意」から同意を撤回して止められます。カメラ・マイク・写真への権限はiOSの設定から変更できます。撤回前に行われた処理には影響しません。

アカウントとサーバー記録の削除

アプリのプラン・アカウント画面でアカウント削除を選び、Appleで再認証し、購読は別途解約が必要なことと保持内容を確認して確定します。通信が途切れた場合は削除状況を確認し、必要なら同じAppleアカウントで再認証してください。完了するまで認証・削除の回復情報を保持します。削除完了後の受領証は1日、再送防止記録は10分を有効期限として保守処理で消去します。削除後の再登録では当日の無料枠がリセットされます。

Appleの購読はアカウント削除やアプリ削除で停止しません。Appleの設定から別途解約してください。Appleの購読解約案内をご確認ください。写真アプリや共有先・バックアップにあるコピーも別途管理が必要です。

サーバー記録の削除依頼

下記へ「BestShot データ削除依頼」としてメールをお送りください。オンライン選定を行ったおおよその日時・タイムゾーンと、対象を特定するために共有可能な最小限の情報をお知らせください。選定IDがお手元にある場合は添付できますが、アプリ内では表示されないため必須ではありません。

アカウント利用版では、先にアプリのアカウント削除を利用できます。旧版のアカウントにひもづかない記録は追加確認が必要な場合や、一意に特定できない場合があります。他人の記録を削除しないよう確認し、対応結果または制限がある理由をお知らせします。

削除の対象と範囲

サーバーには選定条件・結果等のメタデータと利用枠・認証・購読照合記録を保存し、候補画像や動画はデータベースに保存しません。アカウント削除では当該アカウントにひもづく記録を消去します。旧版のひもづかない記録については、対象を特定できる範囲で削除依頼を受け付けます。

OpenAI、Cloudflare、メール基盤、Apple、共有先の保持・バックアップ等には各サービスの方針や法的義務が適用されます。法令や安全対策上の保持が必要な場合や、技術上の制約で直ちに削除できない場合は、その範囲を説明します。詳細はプライバシーポリシーをご確認ください。
