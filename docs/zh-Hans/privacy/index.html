隐私政策

运营者与适用范围

sunagaku（BestShot的开发者及运营者）制定本政策，适用于BestShot iOS应用、在线选片服务以及本网站所处理的信息。如有疑问，请通过以下邮箱联系我们。

sunagaku.dx@gmail.com

设备端的信息

  • 拍摄或导入的视频、提取的照片、选片要求和结果、名称及图库历史记录保存在设备的应用存储空间中。如果允许使用麦克风，拍摄的视频可能包含声音。
  • 测试连接码保存在设备的Keychain中，选片模式等偏好设置保存在本地。
  • 只有当您主动操作时，才会将内容保存到系统照片图库或分享给其他应用。根据iOS及备份设置，设备端数据可能被包含在Apple备份中。

在线AI选片发送的信息

您在发送前的确认页面同意后，最多12张缩小的JPEG候选图片、选片要求（含自由输入的文字）、画面ID、视频内的相对时间点及设备计算的画质分数，会经BestShot服务器发送给OpenAI。我们不会为了AI选片发送完整原始视频、视频音轨或全分辨率提取照片。

图片中可能包含人脸、背景和可见文字。拍摄或发送前，请确认您拥有所需权利，并已取得被拍摄者或其监护人等的必要同意。请避免在图片或选片要求中包含敏感信息。

设备端模式不会为了选片将图片或要求发送给BestShot服务器或OpenAI，仅比较亮度和清晰度，不理解表情或文字要求的含义。

服务器记录和使用目的

BestShot数据库保存选片ID、选片要求、处理服务及模型名、候选数量、所选画面的ID、排名、分数、理由及创建时间。此外，还保存请求ID和时间信息，用于使用额度管理。这些信息用于提供选片服务、检查运行情况、排查故障，以及防止滥用和过量使用。

候选图片、原始视频和连接码不保存在该数据库中。图片在传输和处理过程中会被临时处理。正常运行时，应用日志不会输出请求正文或OpenAI错误正文。

当前版本没有用户账户注册功能，不要求填写姓名或邮箱，也不获取广告标识符。不提供用于识别个人的人脸认证或推断敏感个人属性的功能。我们不出售数据，也不为广告目的跟踪用户。

服务提供方与跨境处理

  • OpenAI处理候选图片及要求并返回选片结果。我们向Responses API设置store: false，但这不代表禁用一切保留。滥用监测、图片安全检查及其他例外，依照OpenAI API数据处理说明及相应服务设置执行。
  • Cloudflare提供API网络、运行及数据库基础设施。IP地址等连接信息可能因基础设施运行和安全需要而被处理。请参阅Cloudflare隐私政策。
  • GitHub Pages托管本网站。GitHub会出于安全目的记录访问者IP地址。本网站未添加广告、访问分析脚本或基于Cookie的跟踪。请参阅GitHub隐私声明。
  • Apple提供TestFlight分发、您主动提交的反馈、系统照片及设备备份等服务。相关处理适用Apple隐私政策。
  • 联系邮件包含回复邮箱及您提供的内容，我们仅在回复和核实请求所需的范围内使用。上述服务及邮件基础设施可能在日本以外或您居住地以外的国家、地区处理信息，并适用相应保护措施及法律。

保存期限

设备内的历史记录、照片和视频会保留至您删除。导出到系统照片或分享至其他服务的副本需要分别管理。备份保留及恢复遵循相应服务设置。

当前测试版未对服务器选片元数据或使用额度记录设置自动删除期限。记录会保留至运营者删除，或处理能够识别目标的删除请求。仅删除本地历史记录或卸载应用，不会删除服务器记录。

OpenAI等处理方、备份和安全记录适用各自的保留政策及法律要求，不保证所有副本即时彻底消除。联系邮件会为处理请求和必要记录管理而保留；您可以申请删除不再需要的信息。

撤回同意、删除和其他权利

您可以在发送前取消，或关闭设置中的AI选片选项，以停止今后的AI传输。相机、麦克风和照片权限可在iOS设置中调整。撤回不影响此前已经合法完成的处理。

可在应用内图库中通过拍摄记录的菜单删除数据。服务器记录的删除方法见删除数据。当前版本没有账户，因此没有账户注销流程。

对于适用法律赋予的查阅、更正、删除、限制处理、反对处理、获取或转移数据等权利，请通过邮件提出。我们会根据适用条件，核实请求者及目标记录后处理。您也可能有权向居住地的数据保护监管机构投诉。

未成年人、安全和政策变更

未成年人应根据适用法律取得监护人同意。BestShot并非面向儿童提供的服务。如对儿童信息的处理有疑虑，请联系我们。

我们采用加密传输、API连接码访问控制，并且不提供公开的共享历史记录API。共享设备、导出照片或向其他服务分享时，也请注意信息安全。

功能或数据处理方式改变时，我们会更新本页。重大变更将在应用或本网站上告知，需要新的处理同意时会事先征求同意。
