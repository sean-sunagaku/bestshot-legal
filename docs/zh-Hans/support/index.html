拍摄或导入视频

您可以拍摄5秒视频，或从系统照片中选择30秒以内的视频。选择想保留的瞬间类型，或输入自己的选片要求。

相机、麦克风或保存照片权限有问题时，请在iPhone设置中检查BestShot权限。即使不允许使用麦克风，也可拍摄无声视频。

AI选片与连接错误

AI 筛选需要互联网连接，并按版本使用 Apple 登录或邀请连接码。无需填写 OpenAI API 密钥。候选图像会在单独同意 AI 发送并逐段视频确认后发送。

连接码错误时，请检查邀请说明。出现使用额度或超时提示时，请稍后重试。测试版使用额度可能随运营情况调整。

不希望发送图像时，请在发送前取消，或在设置的“AI 使用与发送同意”中撤回。新版本没有仅在设备内筛选的模式。您仍可浏览和管理图库中已保存的媒体。

保存、分享和删除

选出的三张照片和原始视频会保存在应用内图库。可以从结果页面保存到系统照片，或通过iOS分享至其他应用。

在拍摄记录的图库菜单中选择删除，会移除应用内该记录的三张照片和原始视频。系统照片及其他服务中的副本仍会保留。请参阅删除数据。

费用和语言

账号版本每天最多免费 AI 筛选 3 次，BestShot Pro 最多 30 次，额度在 UTC 0 时更新。Pro 为自动续期月度订阅，价格、周期和续期条件请在 Apple 购买画面确认。不提供免费试用、年度方案或家人共享。只有您在 Apple 画面确认后才会产生购买。请在 Apple 账号设置中管理或取消订阅。删除应用或 BestShot 账号不会取消订阅。

网站支持日语、英语、简体及繁体中文、韩语。新应用支持日语、英语、简体中文和韩语。切换网站语言不会更改应用语言。
