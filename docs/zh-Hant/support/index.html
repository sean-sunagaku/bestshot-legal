拍攝或匯入影片

您可以拍攝5秒影片，或從系統照片中選擇30秒以內的影片。選擇想保留的瞬間類型，或輸入自己的選片要求。

相機、麥克風或儲存照片權限有問題時，請在iPhone設定中檢查BestShot權限。即使不允許使用麥克風，也可拍攝無聲影片。

AI選片與連線錯誤

AI 篩選需要網際網路連線，並依版本使用 Apple 登入或邀請連線碼。無須填寫 OpenAI API 金鑰。候選影像會在個別同意 AI 傳送並逐段影片確認後傳送。

連線碼錯誤時，請檢查邀請說明。出現使用額度或逾時提示時，請稍後重試。測試版使用額度可能隨營運情況調整。

不想傳送影像時，請在傳送前取消，或在設定的 AI 使用與傳送同意中撤回。新版本沒有僅在裝置內篩選的模式。您仍可瀏覽和管理圖庫中已保存的媒體。

儲存、分享和刪除

選出的三張照片和原始影片會儲存在應用程式內圖庫。可以從結果頁面儲存到系統照片，或透過iOS分享至其他應用程式。

在拍攝紀錄的圖庫選單中選擇刪除，會移除應用程式內該紀錄的三張照片和原始影片。系統照片及其他服務中的副本仍會保留。請參閱刪除資料。

費用和語言

帳號版本每天最多免費 AI 篩選 3 次，BestShot Pro 最多 30 次，額度在 UTC 0 時更新。Pro 為自動續訂的月訂閱，價格、週期和續訂條件請在 Apple 購買畫面確認。不提供免費試用、年方案或家人共享。只有您在 Apple 畫面確認後才會產生購買。請在 Apple 帳號設定管理或取消訂閱。刪除 App 或 BestShot 帳號不會取消訂閱。

網站支援日文、英文、簡體及繁體中文、韓文。新 App 支援日文、英文、簡體中文和韓文。切換網站語言不會更改 App 語言。
