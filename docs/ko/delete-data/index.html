기기 내 사진과 동영상

  • BestShot 라이브러리에서 대상 촬영 기록의 메뉴를 열어 삭제를 선택합니다. 확인하면 해당 기록의 사진 세 장과 원본 동영상이 앱에서 삭제됩니다.
  • 내보낸 사본은 사진 앱에서 별도로 삭제하세요. 최근 삭제된 항목, iCloud 사진, 기기 백업 설정도 확인하세요. 공유한 사본은 공유 대상에서도 처리해야 합니다.
